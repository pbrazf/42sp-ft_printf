# ft_printf

`ft_printf` is a reimplementation of the C standard `printf` function, developed as part of the 42 São Paulo curriculum.  
The project focuses on formatted output, variadic functions, and low-level control over data representation.

## 📚 Supported Conversions
The function supports the following format specifiers:

- `%c` – character
- `%s` – string
- `%p` – pointer address
- `%d` / `%i` – signed integers
- `%u` – unsigned integers
- `%x` / `%X` – hexadecimal (lowercase / uppercase)
- `%%` – percent sign
